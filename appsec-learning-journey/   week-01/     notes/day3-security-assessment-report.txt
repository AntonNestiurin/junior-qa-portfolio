# Security Assessment: Test Web Application
**Date:** 12.02.2026  
**Tester:** Anton Nestiurin  
**Target:** http://127.0.0.1:5000 (Local Flask server)

---

## Executive Summary
Tested session management and cookie security on a local Flask server. Identified two issues and verified positive security measures.

---

## Findings

### 1. Missing Secure Flag on Session Cookie
- **Severity:** HIGH
- **Description:** Session cookie lacks Secure attribute.
- **Impact:** Cookie transmitted over HTTP; vulnerable to interception.
- **Steps to Reproduce:**
  1. Visit http://127.0.0.1:5000
  2. Login
  3. Observe Set-Cookie header lacks "Secure"
- **Remediation:**  
  - Use HTTPS  
  - Or set `app.config['SESSION_COOKIE_SECURE'] = True`

### 2. Missing SameSite Flag
- **Severity:** MEDIUM
- **Description:** Session cookie lacks SameSite attribute.
- **Impact:** Vulnerable to CSRF attacks.
- **Remediation:**  
  - Set `app.config['SESSION_COOKIE_SAMESITE'] = 'Lax'`

---

## Positive Findings
- HttpOnly flag present (protects against XSS)  
- Session regenerates after login (protects against fixation)

---

## Risk Assessment
- **Overall:** MEDIUM (due to HTTP usage; test environment)
